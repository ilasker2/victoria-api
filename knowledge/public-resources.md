# Example Pitches and Public Resources

> **Source:** Appendix F (Example pitches and public resources)
> **Type:** Reference list of public sources. Link to these; do not copy their content.
> **Links last checked by the course authors:** October 14, 2026
> **Related files:** `knowledge/investor-profiles.md`, `knowledge/investor-qa.md`
> **Runtime:** The server may fetch these URLs when coaching on seed, terms, or benchmarks. Cite by name and URL.

## How the agent should use this file

- Point founders to these resources by name and link. Do not reproduce or closely paraphrase their content.
- If the agent states an investor expectation or benchmark, it must cite one of these resources or another public source, and name it (title + publisher + URL).
- Before stating a figure from a linked page, the server must have fetched that page into the session context. If fetch failed, link out — do not invent the page's contents.
- Prefer seed fundraising (#8–#16) and terms (#17–#18) when coaching on raise stage, angels/VCs, SAFEs, or term-sheet vocabulary.
- Some sources are US data or US legal forms. If the agent uses them for a Canadian company, it must say so.
- If no source supports a benchmark, the agent says so and does not quote one.
