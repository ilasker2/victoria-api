## How the agent should use this file

- Use these examples only when coaching Tidewell. They are not benchmarks for any other company.
- Recalculate each figure from the case files before quoting it, and state the method. Several figures depend on customer-level data that may not have been provided (see the data files table in `case-index.md`). If a figure can't be reproduced, say so.
- Label every figure as historical, forecast, founder's claim, or public source.
